# 示例：reBot B601-RS + C1 转接件 + TacCap G1 夹爪

一台改装的 reBot B601 灵足版的完整辨识结果，以及采到的全部静态数据。可以不接硬件跑通辨识流程，也能看到实际效果。

> 这里的参数只适用于这台机械臂和这套安装（拆掉原厂 link6 法兰，C1 直接装在第六轴电机输出面上，下面是 TacCap G1 从夹爪）。别的机械臂请重新标定、采数据、辨识。

## 内容

| 位置 | 内容 | 是否在 Git 里 |
|---|---|---|
| `data/arm/` | 本体静态数据（拆掉 C1 和夹爪），4 个 CSV，130 个位姿 | 是 |
| `data/gripper/` | 装上 C1 和夹爪的静态数据，12 个 CSV，159 个位姿 | 是 |
| `reference/` | 本次辨识的参数记录：`result.json`、`payload.json`、`inputs.json`、关节力矩偏置 `_offset.yaml` | 是 |
| `reproduce.sh` | 从 `data/` 重新辨识并导出 URDF 包的脚本 | 是 |
| `output/` | `reproduce.sh` 的输出 | 否（运行时生成） |
| GitHub Release `rebot_b601_rs_taccap_v2_urdf.tar.gz` | 导出的完整 URDF 包（`urdf/` + `meshes/` + 许可），约 35 MB | Release 附件 |

CSV 每行一个静止位姿：关节角 `q_deg*`、实测保持力矩 `tau_meas*`、采集时的模型重力 `tau_model*`、静摩擦估计 `static_friction*`、发送的指令力矩 `tau_cmd*`。力矩单位是电机反馈值（N·m），辨识时除以力矩标定。

## 复现

在仓库根目录、装好本项目的环境里运行：

```bash
git submodule update --init --remote -- third_party/XTac-UMI-Description
bash examples/rebot_b601_rs_taccap_v2/reproduce.sh
```

脚本依次运行：

1. `identify`：用 `data/arm/` 辨识 link1–link5 的质量、质心和关节力矩偏置。
2. `payload`：在辨识出的本体上，用 `data/gripper/` 辨识 C1 + 夹爪合起来的质量、质心，并重新估计 J6 力矩偏置。
3. `package`：导出带夹爪、不带夹爪两个完整 URDF 包。

结果在 `output/`，可以和 `reference/` 对照。用的是辨识时的数据和设置，质量、质心和偏置应与 `reference/` 一致；CAD 惯量随第三方模型版本变化。

注意：负载惯量按 CAD 形状缩放，来自 `third_party/XTac-UMI-Description` 当前的夹爪模型；夹爪仓库更新后，导出包里的惯量和几何可能与历史 Release 不同，质量、质心和偏置仍由相同数据拟合。当前 `604573a` 的 C1 + 夹爪 CAD 质量为 0.770 kg，以下 1.169 kg 仅指采集示例时的旧版资产。

## 设置

| 项 | 值 |
|---|---|
| 力矩标定（反馈 / 指令） | `1 1.032 1.08 1.004 1 1` |
| 本体先验权重 | 0.1 |
| 本体训练 | `train_rand50_s0`（50 个随机位姿）+ `drift_20261013_114441_identified_v1`（30 个漂移补点，权重 ×5） |
| 本体验证 | `val_rand20_s100`、`drift_20261013_115149_identified_val_v1` |
| 负载训练 | `train_rand40_s200`–`s203`（中途因跟踪误差停止，共 35 个位姿）+ 6 组漂移补点 |
| 负载验证 | `val_rand20_s300`、`val_rand20_s301` |

## 已知局限

- **伸直时 J2 偏小约 4%。** J2 负载大于 8 N·m 的姿态，实测力矩比模型大 3–5%（电机热时更明显）。free 模式重力补偿在伸直姿态会缓慢下沉；把 J2 前馈倍率设为 1.04（工作台第 3 步“前馈倍率”，或命令行 `--ff-scale 1 1.04 1 1 1 1`）后明显改善。这个倍率没有写进模型。
- **负载训练数据偏少。** 4 组随机负载数据都在中途停止（当时前馈未含负载，伸直姿态超出跟踪误差上限），伸直姿态主要靠漂移补点覆盖。
- **惯量不是辨识值。** 静态数据看不到转动惯量：本体沿用 CAD，负载按 CAD 形状缩放到辨识质量。
- **C1 转接件网格及随附数据采用与 XTac-UMI-Description 相同的 MIT 许可及 Xense Robotics 版权署名**，见导出包 `LICENSES/rebot_b601_rs/LICENSES/C1_ADAPTER_NOTICE.md`。
